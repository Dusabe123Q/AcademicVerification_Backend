3. Phase 10: Detailed Daily Execution

Day 1 & Day 2: Strategic Planning and Unit Logic

Testing began with the creation of a comprehensive test matrix. We then moved to the unit level, testing individual services like AlumniService.java and CredentialService.java using JUnit. We verified that academic records were being persisted correctly to the MySQL database and that the DTO mapping logic was error-free.

Figure 1: Initial System Entry Point and Verification Strategy Planning

Day 3: API End-to-End Validation (Postman)

A full Postman collection was executed against the backend controllers. We simulated various user requests, including registration and document lookup. We confirmed that the system returns proper 200 OK status for successful requests and 401 Unauthorized when security tokens are missing, proving the robustness of our API layer.

Figure 2: Backend Development Log Monitoring and Performance Analysis

Day 4: Security and OTP Flow Verification

This day focused on the Two-Factor Authentication (2FA) flow. We tested the SMTP integration to ensure OTP emails are dispatched instantly upon registration. We verified that accounts remain "Inactive" until the correct 6-digit code is provided, preventing unauthorized credential access.

Example Test Case: "Verified that entering an expired or invalid OTP results in an immediate access denial with a user-friendly error message."
Figure 3: Secure SMTP OTP Verification and User Activation Handshake

Day 5: Bug Resolution and Dashboard Optimization

Following the initial results, we resolved a critical port conflict issue (Port 8081) and optimized the database connection pool. We also verified that the Admin Dashboard accurately reflects real-time statistics from the database, ensuring that charts and growth trends are synchronized correctly.

Figure 4: Strategic Oversight Dashboard Stability and Data Synchronization

Day 6 & Day 7: Final Regression and Documentation

The final days were dedicated to "Regression Testing"—ensuring that the fixes from Day 5 did not introduce new issues. We successfully performed a full user journey simulation (Registration to Degree Verification). The database search logic was tested for high-speed retrieval of Alumni records.
